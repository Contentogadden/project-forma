# Подсказки и адаптивная практика

## Groq

Администратор → «Настройки ИИ» → провайдер Groq → API-ключ из https://console.groq.com/keys → GPT-OSS 20B → включить → сохранить → проверить подключение. Ключ вводится в интерфейсе, не в чате. Проверка выполняет реальный короткий запрос генерации.

Используйте аккаунт Groq на Free-тарифе. Приложение не включает платный тариф, но не может определить тариф ключа: если владелец самостоятельно подключил платный аккаунт, запросы будут тарифицироваться провайдером. При 429/сбое/некорректном ответе возвращается локальная подсказка, без повторных запросов или переключения на другую модель/провайдера.

Поддерживаются `openai/gpt-oss-20b` и `openai/gpt-oss-120b`. Запросы идут только на фиксированный `https://api.groq.com/openai/v1/chat/completions`, с Bearer-заголовком, JSON Schema strict и ограничением ответа. Передаются только тип упражнения, MIDI-ноты и число ошибок — без имени, класса и аккаунта. Подтверждение 18+ и передачи музыкального контекста сохраняется. Результат упражнений проверяет алгоритм, не модель.

Ключи Gemini и Groq хранятся раздельно в серверном файле 0600. Старый файл настроек читается как Gemini, без потери ключа. Удаление убирает только ключ выбранного провайдера и выключает ИИ. Реальный вызов Groq не проверен без пользовательского ключа; протокол и сохранение тестируются офлайн.

Источники: [API](https://console.groq.com/docs/openai), [JSON Schema](https://console.groq.com/docs/structured-outputs), [Free-лимиты](https://console.groq.com/docs/rate-limits).

## Прямое подключение Gemini (18+)

### Настройки через администратора

В кабинете администратора доступна вкладка «Настройки ИИ»: новый ключ, модель, выключатель, проверка подключения и удаление ключа. Сначала сохраните настройки, затем проверьте подключение. Проверка выполняет короткий запрос генерации и расходует API-квоту; без нажатия кнопки настройка сама не обращается к Google.

Секрет хранится только на сервере: по умолчанию `${user.home}/.project-forma/ai.properties`, вне репозитория, права файла 0600 (POSIX). Путь можно заменить свойством `forma.ai.settings-file`. Это защищённый правами ОС файл, **не шифрование**: владельцы процесса и системные администраторы могут прочитать его. Для публичного развёртывания используйте отдельного системного пользователя, HTTPS и защищённый диск/хранилище секретов; не включайте этот файл в открытые резервные копии.

Сохранённые настройки имеют приоритет над переменной окружения, включая удаление и выключение. API возвращает только enabled/configured/model, никогда ключ. Роль проверяется и фильтром безопасности, и по учётной записи в базе. Все изменения и тест подключения защищены CSRF. Выключение ИИ оставляет локальные подсказки. Администраторский ключ общий для приложения: расходы/квота относятся к его Google-проекту.

Добавлен прямой вызов Google generateContent. Достаточно настроить новый GEMINI_API_KEY на сервере; FORMA_AI_GEMINI_MODEL меняет модель, по умолчанию gemini-2.5-flash-lite. Не помещать ключ во frontend, Git или сообщения чата. При наличии Gemini-ключа используется прямой Google API, иначе — ранее описанный шлюз либо локальная подсказка.

Внешний вызов разрешён только при явном adultConsent=true. В интерфейсе подтверждение 18+ и передачи нот по умолчанию выключено; без него подсказка локальная. Позиционирование приложения изменено на взрослых музыкантов. Это самоутверждение возраста, не проверка личности и не гарантия соблюдения условий провайдера: перед публикацией необходимо обеспечить фактически взрослую аудиторию и доступный регион. Нового ключа нет, реальный вызов Google пока не проверен. Тестируется формат запроса/ответа без внешнего API. Бесплатный уровень может использовать отправленный контент для улучшения продуктов Google.

Источник протокола: https://ai.google.dev/api/generate-content . JSON-ответ обязателен; усечённые/заблокированные ответы и HTTP-ошибки переводят запрос на локальную подсказку. По-прежнему нет передачи имён и пользовательских свободных текстов.

В коротких упражнениях неверный ответ больше не раскрывает правильный. Можно попробовать снова или нажать «Помоги услышать». Счёт учитывает только первую попытку; подсказка не меняет оценку. Локальные подсказки доступны без модели.

Подбор следующих вопросов реально адаптируется по ошибкам отдельно для каждого навыка, в памяти текущей сессии. Два из трёх следующих примеров по возможности закрепляют наиболее ошибочную тему. После двух ошибок в ней темп снижается до 60. Верные первые ответы уменьшают вес ошибки. Это прозрачный алгоритм, не решение LLM; журнал на сервере пока не сохраняется.

Для внешней модели реализован серверный адаптер к приватному HTTPS-шлюзу. Настройки: FORMA_AI_HINT_URL и FORMA_AI_TOKEN. Ключ не передаётся браузеру. POST JSON содержит instruction и exercise {kind,pitches,errors}; шлюз должен вызвать выбранную модель и вернуть {"hint":"Короткая подсказка"}. Это нейтральный контракт, не прямая совместимость с API любого провайдера. Внешний шлюз/провайдер ещё не настроен и не проверен.

Запрос защищён сессией и CSRF. Нет имени, класса, аккаунта и истории учеников в отправляемом контексте. Таймаут 4 секунды, два одновременных вызова, не чаще одного запроса на 10 секунд на пользователя; повторные/неуспешные вызовы используют локальную подсказку. Отображается «ИИ-подсказка» только при реальном ответе шлюза. Ответ ограничен 300 символами, выводится как текст, не HTML. Модель не управляет оценкой или выбором правильного ответа. Формулировки модели всё равно требуют проверки педагогом перед публичным запуском; контракт не гарантирует отсутствия раскрытого ответа.
