# Ротация локальных репродукций

Сервер читает `Downloads/Frame Art` в домашнем каталоге пользователя без изменения файлов. Настройка для другого окружения: `FORMA_ART_DIRECTORY` (Spring relaxed binding для `forma.art.directory`). Поддерживаются JPG/JPEG, PNG, WebP в самой папке, без обхода подпапок и символических ссылок.

При каждом открытии страницы API выбирает до шести разных изображений: первый экран и пять тематических карточек. Изображения фиксированы на время просмотра; автоматического переключения и таймеров нет. Новые файлы доступны при следующем открытии/обновлении страницы без пересборки. Случайный выбор может повториться между открытиями.

URLs содержат хеши вместо имён/путей. Сервер отдаёт только перечисленные поддерживаемые изображения. При отсутствии папки/файла или сбое загрузки используются встроенные репродукции. Назначения карточек не меняются. Это визуальная ротация, не классификация содержания картин по музыкальным темам.

Папка нужна на машине сервера. Браузер не читает файловую систему пользователя. Для публичного размещения нужно настроить отдельную библиотеку и подтвердить права на изображения.
