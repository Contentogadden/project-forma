# Самостоятельная проверка

В назначенных мелодических работах кнопка «Проверить себя» вызывает серверную проверку текущих нот. Она не отправляет работу учителю и не меняет статус или сохранённый ответ. После изменения нот предыдущий результат помечается устаревшим.

Учитель выбирает правило в конструкторе:

- Свободный ответ — доступные клавиши, неизменность исходных долей, заполненность и заданное окончание. Художественное качество не оценивается автоматически.
- Точное воспроизведение — изменяемые доли должны совпасть со звуковым образцом.
- Перенос — интервалы изменяемой фразы образца сохраняются при ненулевом сдвиге высоты; принимается любой допустимый перенос.

Старые шаблоны без правила используют свободный ответ. Чтобы проверять перенос в ранее выданных работах, нужно изменить шаблон и выдать новую работу: условия уже выданных заданий остаются неизменными.

Ответ проверки содержит passed, complete, message и incorrectSlots (индексы с нуля). UI показывает номера долей с единицы. Доступ проверяется по владельцу работы, запрос защищён CSRF и версией. Подменённые исходные ноты или недоступные клавиши не могут дать успешный результат.
