# Расширение практики: 160 новых заданий

Для 40 композиторов расширенного каталога добавлено по четыре задания. Вместе с двумя вводными у каждого теперь шесть упражнений.

| Формат | Что делает студент | Что проверяется |
|---|---|---|
| Диктант | Слушает полную линию и восстанавливает три пропуска | Точные высоты в местах 2, 4, 7 |
| Перенос | Повторяет мотив на тон выше или ниже | Сдвиг всех звучащих нот на два полутона, неизменные паузы |
| Ракоход | Собирает восьмизвуковую линию в обратном порядке | Порядок звуков во времени, без обращения интервалов |
| Узнавание | Сравнивает три одинаково ритмизованные линии | Один вариант без подмены высот; в остальных изменена одна нота |

Исходный материал индивидуален для композитора и взят из существующих оригинальных учебных моделей Forma. Эти упражнения тренируют общие навыки, а не доказывают принадлежность приёма одному автору. Они не являются цитатами из произведений или полноценным курсом исторического стиля.

В диктанте ноты образца скрыты во время проигрывания. Повторы и подсказки разрешены: это самостоятельная практика, не экзамен. Автопроверка редактора указывает номера ошибочных мест. Формат можно выбрать в профиле композитора: «Собрать», «На слух», «Диктант».

Новые задания используют существующие записи фортепиано, сравнение образца с ответом, отмену правок и сохранение работы в аккаунте. Ответы и описания хранятся в общем ресурсе `src/main/resources/catalog/composer-paths.json`, который читают Java и TypeScript.

После расширения: 54 композитора, 289 заданий по композиторам, 294 готовых интерактивных задания с учётом пяти базовых, 295 тем в API с учётом одной исследовательской заготовки.
