The expanded set retains each file's individual license below, including CC BY-SA where applicable; do not assume every new portrait is public domain. Local copies use supplied thumbnails or originals. PNG/GIF sources are converted to JPEG, with their license retained. The interface additionally crops with CSS and overlays a decorative grid. These are historical portraits/photos, not generated likenesses.
