# Project Forma

Вертикальный срез сервиса музыкального образования: Spring Boot API, ролевая авторизация и редакционный React-интерфейс.

## Структура кода

Лендинг находится в `frontend/src/App.tsx`. Вход, кабинет и навигация разделены
на `Login`, `Dashboard` и `Workspace`. Панели класса лежат в `frontend/src/classroom/`.
В тренажёрах `useMusicPlayback` управляет звуком, а `useMusicWork` — загрузкой и сохранением.
Общие запросы и CSRF находятся в `http.ts`, конструкторы учебных материалов — в `studyBuilders.ts`.
На сервере правила допустимости мелодического задания вынесены в `MelodyDefinitionValidator`.

Из папки `frontend`: `npm test`, `npm run build`, `npm run format:check`.
`npm run format` форматирует также серверный код и тесты. Серверные тесты: `mvn test` из корня.

## Локальный запуск

```bash
# Терминал 1 — API
mvn spring-boot:run

# Терминал 2 — интерфейс
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`. API доступен по `http://localhost:8080/api/v1/content/landing`.

## Демонстрационный доступ

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `FormaAdmin!26` |
| Преподаватель | `teacher` | `FormaTeacher!26` |
| Ученик | `student` | `FormaStudent!26` |

Это локальные учётные записи. При публикации задайте `FORMA_ADMIN_PASSWORD`,
`FORMA_TEACHER_PASSWORD`, `FORMA_STUDENT_PASSWORD` и отключите демо-инициализацию
через `FORMA_DEMO_ACCOUNTS=false`. Пароли сохраняются только как BCrypt-хэши.

## Данные и безопасность

- локальная файловая H2-база лежит в `data/`;
- production-профиль рассчитан на PostgreSQL и переменные `DATABASE_*`;
- аутентификация использует серверную HTTP-сессию, CSRF-токен и HttpOnly cookie;
- маршруты зарезервированы по ролям: `/api/admin/**`, `/api/teacher/**`, `/api/student/**`.

## Звуковая мастерская

В кабинете доступны восемь интерактивных занятий: мелодический ответ, гармония,
смещение акцентов, форма A–B–A′, регистр и тембр, перенос мотива,
группировки 3+3+2 / 2+3+3 и группы по два внутри размера 3/4.
Есть воспроизведение, остановка, метроном, темп, громкость и подсветка позиции.
Музыкальные ноты звучат записями Yamaha C5 из Salamander Grand Piano
(Alexander Holm, CC BY 3.0). Компактная библиотека из 17 MP3 хранится на сайте,
занимает около 1,2 МБ, загружается при первом прослушивании и повторно используется
между упражнениями. Между записанными нотами используется транспозиция.
Это один динамический слой, не полный многослойный виртуальный рояль.
Только метроном синтезируется. Все последовательности — учебные модели Forma,
не записи произведений. Источник и атрибуция: `frontend/public/audio/piano/ATTRIBUTION.md`.
Проверка оценивает условия упражнения, а не художественное качество.

Формат занятий: услышать образец, изменить материал, сравнить обе версии.
Мелодии представлены нотной строкой и клавишами, гармония — заданным басом
и палитрой трезвучий, ритм — отдельными тактами. Есть отмена последнего изменения.
Работа с заданным басом и развитие мотива — вводная адаптация подхода
А. С. Аренского, а не воспроизведение его исторических задач или полный курс.
См. `docs/pedagogy.md`.

Кнопка «Сохранить работу» сохраняет музыкальные данные в серверной базе
для текущего аккаунта. Девять остальных тем каталога пока обозначены как эскизы.

## Класс, конструктор и администратор

Преподаватель создаёт своё мелодическое задание: задаёт исходные ноты и звуковой
образец, выбирает изменяемые доли, доступные клавиши, темп и условие окончания.
Есть предпросмотр глазами ученика. Два существующих упражнения, «Вопрос и ответ»
и «Мотив на новой высоте», можно открыть в практике и скопировать в конструктор.

Задание назначается отдельным ученикам или всему составу группы. Ученик видит его
в «Назначено мне», сохраняет черновик и отдельно отправляет музыкальный ответ.
Преподаватель слушает ответ, принимает его или возвращает с комментарием.
История сохраняет ноты каждой отправленной версии. Изменение шаблона не меняет
уже выданные условия. Существующая свободная практика остаётся отдельным разделом.

Администратор создаёт пользователей и группы, меняет состав, имя и доступ,
устанавливает новый пароль другим пользователям. Блокировка, смена роли и пароля
завершают прежние сессии. Роль аккаунта с группами или учебными работами менять
нельзя; собственный административный доступ отключить нельзя. Журнал показывает
последние 100 административных действий без паролей.

Подробности, права доступа и границы первой версии: `docs/classroom.md`.
